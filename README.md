# Smart Campus Complaint Portal
A role-light campus issue reporting portal using Flask and SQLite.

## Run
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Visit http://127.0.0.1:5000

## Features
- Submit campus complaints with category, location and priority
- View all complaints and their status
- Update complaint status (New, In Progress, Resolved)
- Persistent SQLite storage
